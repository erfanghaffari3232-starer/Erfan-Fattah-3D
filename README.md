# Erfan Fattah-2 3D

نمایشگاه سه‌بعدی تعاملی و فارسی با الهام از ماکت ارسالی.

## امکانات
- نمایش سه‌بعدی با Three.js و کنترل چرخش، زوم و زاویه دید
- جلوه‌ی بصری پرتاب نمایشی و دود، بدون محاسبات یا اطلاعات عملیاتی
- گالری تصاویر ماکت در مسیر `assets/model-01.jpg` تا `assets/model-18.jpg`
- طراحی واکنش‌گرا و راست‌چین

## اجرا
فایل `index.html` را روی وب‌سرور یا GitHub Pages منتشر کنید. برای دریافت Three.js از CDN اینترنت لازم است.

## تصاویر
پوشه‌ی `assets` فعلاً راهنما دارد. عکس‌های اصلی را در آن با نام‌های `model-01.jpg` تا `model-18.jpg` بارگذاری کنید؛ سپس گالری به‌صورت خودکار آن‌ها را نمایش می‌دهد.

## GitHub Pages
در **Settings → Pages**، گزینه‌ی **Deploy from a branch**، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و ذخیره کنید.

> این یک مدل هنری و آموزشی است، نه بازسازی مهندسی. هیچ محاسبه یا راهنمایی درباره فشار، رانش، بارگذاری یا طراحی پرتاب ارائه نمی‌کند.
